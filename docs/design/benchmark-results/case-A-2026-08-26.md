# Case A — 跨 session 显式事实

**日期**：2026-08-26
**固定条件**：
```text
DSH commit:        2c2da5acf555d2828ae511292f704f79cffc72be（master，benchmark 时分支 fix/benchmark-fg）
LLM:               host（DSH host LLM，benchmark 确定性路径未调用）
embedding:         MemOS local（all-MiniLM-L6-v2 q8，已修复模型缓存）
context budget:    900 tokens
temperature:       0

```

## 过程
S1 写入显式事实（"这个项目 package manager 一律用 pnpm"，user_explicit）→ S2 查询（"package manager 怎么选"）。

|---|---|---|---|

> 注：memosRecallCount=0 属预期——benchmark 为独立进程直接写 ACP Ledger，MemOS 仅捕获 DSH turn 内会话，不共享写入。MemOS 侧集成由挂载实测覆盖。

## 结论
**通过**。本地 Ledger 跨"session"（不同 sourceRef）累积 recall 正确，无 hallucinated fact；首跑延迟 23ms（embedder 修复前为 3006ms——MemOS search 每次 10.7s 超时导致 fail-open 降级）。
